## 2024-03-05 - Accessibility for Configuration Icon-Only Buttons
**Learning:** During the review of the configuration components (`Variant` configurations, file listings), we observed that many icon-only buttons (download, remove, move up/down, delete mappings/rules) were lacking descriptive ARIA labels (`aria-label`) and explicit keyboard focus indicators (`focus-visible:ring-2` styling with appropriate colors). These interactions are critical for navigating complex forms without a mouse, and default browser outlines often fall short or do not align well with dark UI styling.
**Action:** When working on complex nested lists (like mappings, rules, variants, uploads) with action icons (trash, download, arrows), always verify that they have an explicitly descriptive `aria-label` specifying *what* they affect (e.g., "Delete Variant 1"), and apply explicit keyboard focus styling.## 2023-10-27 - [A11y Enhancements in Complex Custom Inputs]
**Learning:** Found that custom color inputs bundled with text inputs in complex grids easily lose their semantic meaning for screen readers and keyboard users if not explicitly linked with `htmlFor` and `aria-label`. The lack of focus-visible styles also makes keyboard navigation confusing.
**Action:** Always ensure `htmlFor` is used on labels connecting them to their corresponding `id`s on inputs, apply descriptive `aria-label`s to custom non-text inputs (like `type="color"` and `type="range"`), and add explicit focus states (`focus-visible:ring-2`) to improve keyboard accessibility.

## 2023-10-27 - [Mobile Sticky Action Bar for Conversion Tools]
**Learning:** Found that long configuration panels on mobile force the user to scroll endlessly to find primary conversion/download actions, creating a frustrating experience.
**Action:** When building complex form-based conversion tools, always extract primary call-to-actions ("Apply", "Download") into a sticky bottom bar (`fixed bottom-0`) on mobile (`md:hidden`) with appropriate bottom padding (`pb-28`) on the main container to prevent overlap.
